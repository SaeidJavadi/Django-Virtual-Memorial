# 🕯️ Virtual Memorial

**Virtual Memorial** is a web-based platform built with **Python** and the **Django framework** that allows people to honor and commemorate the memory of their deceased loved ones in a respectful and meaningful way.

The project provides a digital space where memories can live on and be shared easily with friends, family, and communities.

---

## 🌟 Features

- **User Registration**
  - Secure user registration using a contact number.

- **Memorial Creation**
  - Users can create memorial pages for their deceased loved ones by adding basic information such as name and photo.

- **Unique Shareable Links**
  - Each memorial page automatically generates a **unique short link** that can be shared with friends, family, and acquaintances.

- **Religious & Spiritual Commemoration Tools**
  - Built-in Islamic devotional options, including:
    - 📖 Fatiha
    - 🌿 Salawat
    - 📜 Recitation of Quran (by part or full completion)
  - These tools allow visitors to participate in acts of remembrance and prayer.

- **Multi-Faith & Inclusive Design**
  - The platform is **open to all religions and sects**.
  - Developers and contributors can add commemoration tools specific to other faiths and traditions.

- **Extensible & Customizable**
  - Designed for easy customization and future expansion.
  - Ideal for both personal use and community-based memorial services.

---

## 🛠️ Tech Stack

- **Backend:** Python, Django  
- **Database:** SQLite (default, can be replaced with PostgreSQL or others)  
- **Frontend:** Django Templates, HTML, CSS  
- **Authentication:** Contact-number-based user system  

---

## 🎯 Purpose

The goal of **Virtual Memorial** is to provide a respectful digital space where memories can be preserved, shared, and honored—regardless of cultural, religious, or geographical boundaries.
